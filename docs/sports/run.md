# Corsa («Run»)

Attività `running`. Rete foot (il filtro `walk` di OSMnx senza l'esclusione delle ciclabili, ADR-0022), 1–50 km nel motore. Lo sport di partenza di MuW.

## Misure di base (TASK-376)

*Da fare, col turno del Coordinatore:*
`python tools/sport_bench/sport_bench.py run --activity running --label base-2026-11`.
Sono il riferimento con cui ogni modifica del motore si confronta
(`compare`).
